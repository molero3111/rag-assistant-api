# Contributing to Tutor Assistant

Thank you for your interest in contributing! Please read these guidelines to help us maintain a high-quality, welcoming project.

## How to Contribute
- **Bug Reports:** Use GitHub Issues to report bugs. Please include steps to reproduce, expected behavior, and screenshots/logs if possible.
- **Feature Requests:** Open an issue describing your idea and its use case.
- **Pull Requests:**
  1. Fork the repository and create your branch from `main`.
  2. Write clear, concise commit messages.
  3. Add/modify tests as needed.
  4. Ensure code passes linting and tests (`pytest`, `flake8`, `black`).
  5. Submit a pull request and describe your changes.

## Code Style
- Follow [PEP 8](https://pep8.org/) for Python code.
- Use type hints and docstrings for all public functions/classes.
- Run `black` and `flake8` before submitting.

## Review Process
- All PRs require at least one approval.
- Address review comments promptly.

## Community
- Be respectful and inclusive. See our [Code of Conduct](CODE_OF_CONDUCT.md).

Thank you for helping us build a better Tutor Assistant!
